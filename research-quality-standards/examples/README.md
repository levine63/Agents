# Positive Examples

Version: 0.1.0
Last updated: 2026-05-06

This folder should contain a small number of positive examples that show what compliant work looks like.

Recommended first examples:

- `good_python_script.py`
- `good_stata_do_file.do`
- `good_summary_statistics_table.md`
- `good_results_memo.md`
- `good_interview_notes.md`

Selection rules:

- examples should reflect actual house style
- examples should be short enough to study quickly
- examples should be clearly labeled by genre and stage
- examples should be replaced if standards evolve materially
