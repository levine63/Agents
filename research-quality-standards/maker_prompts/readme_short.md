# README Maker Prompt

Write a project README that lets a new contributor get from clone to one meaningful visible output with minimal guessing.

Required:

- identify the project genre
- include a short `Quick Start` with expected output
- list exact runtimes, lockfiles, and system dependencies
- explain main inputs, outputs, assumptions, and tests
- include `Limitations and Risks` plus `Not Included`
- use repo-relative paths in documentation examples
- say which steps are deterministic versus model-driven or external

Be honest about missing pieces, slow first runs, gated data, paid APIs, or nondeterministic behavior.
