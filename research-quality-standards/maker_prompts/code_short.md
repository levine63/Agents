# Code Maker Prompt

Produce clear, runnable code that another RA can execute without guesswork.

Required:

- start with a provenance header
- document inputs, outputs, setup, and usage
- avoid hard-coded personal paths
- do not silently swallow exceptions
- if randomness is used, set and document a seed
- explain non-obvious logic briefly

If statistical analysis is involved, also load `maker_prompts/stats_code_short.md`.
