# General Maker Prompt

Use the relevant template and keep this artifact easy to audit.

Required:

- include author, date, intent, inputs, assumptions, and `Not Yet Done`
- distinguish facts from inference
- state important uncertainty plainly
- do not silently omit requested components
- make platform formatting match the target output

If the task is late-stage, behave as if another RA must reproduce or review it without guessing.
