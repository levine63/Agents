# Weekly Report Template

## 1. Outputs Delivered

Only list completed work.

Format:

- `Task | Output | Link/File | Time spent | Quality (1-5)`

Example:

- `Literature review | Summary table of 12 papers + 1-page synthesis | [link] | 5h | 4`

## 2. In-Progress Work

Format:

- `Task | Progress (%) | Next step | Blocker | Carried over? (Y/N)`

Definition:

- carried over = planned last week but not finished this week

Example:

- `Data cleaning | 70% | Fix missing values | Need codebook | Y`

## 3. Next Week Plan

List 3 to 5 items.

Format:

- `Parent goal | Task | Deliverable | Definition of done | Deadline | Hours | Priority (H/M/L)`

Example:

- `Baseline data quality checks | Survey analysis | Table of results | Done when the results table and short interpretation note are saved in the project folder | Friday | 6h | H`

Rules:

- each item should produce a concrete deliverable
- each item should be feasible within one week
- avoid vague verbs such as `work on`, `continue`, `help with`, or `make progress on`

## 4. Blockers, Delays, and Requests

Format:

- `Issue | Why it matters | What you tried (with dates) | What you need | By when`

Example:

- `Need dataset | Cannot run analysis | Asked team (Mon) | Data file | Wed`

Blockers should be explicit, not implied.
