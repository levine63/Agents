These templates are meant to make compliance easier, not to force identical writing.

## Current Templates

- `python_header.py`
  Starter Python script with provenance header, path centralization, seed placeholder, and end-to-end flow.
- `stata_header.do`
  Starter Stata do-file with provenance header, `version`, `set more off`, path centralization, and merge/filter logging reminders.
- `report_skeleton.md`
  General report or memo template with audience, evidence, methods, limitations, and next steps.
- `manuscript_draft_template.md`
  Manuscript-oriented draft template with abstract, methods, limitations, references, and consistency checklist.
- `interview_notes_template.md`
  Interview template with metadata, consent, quotes, observations, interpretation, and follow-up questions.
- `statistical_results_template.md`
  Results summary template with sample definition, variable definitions, summary statistics, model specification, and interpretation.

## Use Rule

Choose the closest template first, then adapt it. If repeated work keeps needing the same edits, improve the template rather than re-explaining the structure in prompts.
