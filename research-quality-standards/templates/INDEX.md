# Templates Index

## Purpose

This index tracks the canonical reusable templates in this repository.

## Organization rule

Templates live in `templates/`.

Standards and reviewer prompts live in `standards/`.

If a standard wants to point to a template, use a normal relative Markdown link rather than storing the template beside the standard.
