# Levine practice site

This folder is structured for GitHub Pages.

## Files
- `index.html`: homepage
- `levine-publications.html`: publications page
- `levine-teaching.html`: teaching and materials page
- `site_assets/`: local PDFs and images used by the site

## GitHub Pages
If this folder is published from the repository root on the default branch, GitHub Pages will serve `index.html` automatically.
